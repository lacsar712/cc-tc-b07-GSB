# 隧道收敛测缝台

测量员登记里程桩号、部位类别与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

页眉挂「合成专页」：勾选至少两笔同类（拱顶 / 边墙 / 注浆段）已办结单，先预览后台平均，再点生成。平均值一律由后台计算；生成的新待认领单与合成流水在同一事务一并记账。

## 合成规则

- 至少勾选两笔，不够两笔拒收。
- 只能勾已办结单，勾进未办结（含注浆段）拒收。
- 同一笔合成必须是同一部位类别，拱顶、边墙、注浆段互不混勾。
- 新单毫米值 = 后台算出的来源平均，状态为待认领（pending），由认领线程后续判定，不得直接写成已办结。
- 巡检员（inspector）可预览，不能点生成（403）。
- 预览只试算不落库；生成时新单与合成流水一起记账，缺一边整体回滚。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/merges/preview` | 登录 | 勾选试算，返回类别、笔数、后台平均，不记账 |
| GET | `/api/merges/preview?ids=1,2` | 登录 | 同上，查询串形式 |
| POST | `/api/merges` | 测量员 | 生成合成单：新待认领单 + 合成流水同一事务落库 |
| GET | `/api/merges` | 登录 | 合成流水列表（来源单号、新单号、平均毫米） |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
